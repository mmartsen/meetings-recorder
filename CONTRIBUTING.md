# Contributing

Thanks for your interest in this project!

## Pull requests

This is a personal project, and **code contributions are not accepted**. Pull requests
will be closed without being merged. Please don't take it personally. It just keeps the
project easy for me to maintain.

Since the code is released into the public domain (see [LICENSE](LICENSE)), you're free
to fork it and change it however you like.

## Issues

You're welcome to [open an issue](https://github.com/mmartsen/meetings-recorder/issues) for:

- **Bug reports**: include your distro, desktop environment (and X11 or Wayland), the
  meeting app involved, what you expected, and what happened. Logs from running the
  binary in a terminal (or `journalctl --user -u meeting-recorder`) help a lot.
- **Feature requests and ideas**: describe the use case, not just the solution.
- **Questions** about setup or configuration.

I can't promise a response time or that every request will be implemented, but every
issue gets read.
